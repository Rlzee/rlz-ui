## Usage

Run the CLI with `npx`; no global installation is required.

```bash
npx rlz@latest <command>
```

For project setup and the Creator preset workflow, see [Installation](/docs/installation).

To check the options for a command:

```bash
npx rlz@latest --help
npx rlz@latest init --help
```

## Commands

<div className="[&_a]:no-underline">

| Command | Purpose |
| ------- | ------- |
| [`init`](#init) | Configure rlz-ui in an existing project |
| [`add`](#add) | Install a component, hook, or lib |
| [`list`](#list) | Browse available registry items |
| [`info`](#info) | Inspect a registry item |

</div>

### init

Initialize rlz-ui in an existing project. Detects your framework, TypeScript, and Tailwind setup automatically.

```bash
npx rlz@latest init
```

| Flag             | Description                                             |
| ---------------- | ------------------------------------------------------- |
| `--font-sans`    | Sans font family                                        |
| `--font-heading` | Heading font family                                     |
| `--font-mono`    | Monospace font family                                   |
| `--icon-lib`     | Icon library to use                                     |
| `--preset`       | Path to a local JSON preset exported from the Creator |

See [Installation](/docs/installation) for requirements and [Presets](/docs/presets) for the Creator workflow and supported customizations.

### add

Add a component, hook, or lib to your project. Dependencies are resolved and installed automatically.

```bash
npx rlz@latest add <name>
```

Requires an initialized project. Uses the saved project preset, if configured.

| Flag | Description |
| ---- | ----------- |
| `--overwrite` | Replace the requested component without confirmation |

If the requested component already exists, the CLI asks before replacing it.
The default is **No**. Use `--overwrite` to replace it without a prompt, including
in non-interactive mode. This replaces the file rather than merging your changes.
Existing dependencies are never overwritten by `add`.

```bash
npx rlz@latest add button --overwrite
```

Back up local component edits before replacing a file.

### list

List all items available in the registry. Use `--type` to filter by category.

```bash
npx rlz@latest list
```

| Flag           | Description                                   |
| -------------- | --------------------------------------------- |
| `--type`, `-t` | Filter by type: `component`, `hook`, or `lib` |

```bash
npx rlz@latest list --type component
```

### info

Show detailed information about a registry item, including its dependencies and registry dependencies.

```bash
npx rlz@latest info <name>
```

For example:

```bash
npx rlz@latest info button
```
