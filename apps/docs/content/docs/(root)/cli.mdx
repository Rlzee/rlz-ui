## Installation

```bash
npx rlz@latest <command>
```

## Commands

### init

Initialize rlz-ui in an existing project. Detects your framework, TypeScript, and Tailwind setup automatically.

```bash
npx rlz@latest init
```

| Flag             | Description                                             |
| ---------------- | ------------------------------------------------------- |
| `--font-sans`    | Sans font family                                        |
| `--font-heading` | Heading font family                                     |
| `--font-mono`    | Monospace font family                                   |
| `--icon-lib`     | Icon library to use                                     |
| `--preset`       | Path to a local JSON preset exported from the Creator |

To use a preset exported from the Creator:

```bash
npx rlz@latest init --preset ./my-preset.json
npx rlz@latest add button
```

Installing presets from the registry is not available yet. Use a local JSON export from the Creator.
`init` saves a snapshot under `.rlz/presets/` so later installs use the same
preset. Keep that snapshot with your project along with `rlz.config.json`.

`init` also applies the preset's base settings, shared utilities (including focus
styles), and animations, even when its color list is empty. Shared utility
overrides replace their existing `@apply` classes; custom utilities are added to
`@layer utilities`. An empty class list clears that utility's `@apply` classes,
while utilities absent from the preset keep their shipped definitions.

### add

Add a component, hook, or lib to your project. Dependencies are resolved and installed automatically.

```bash
npx rlz@latest add <name>
```

If the requested component already exists, the CLI asks before replacing it.
The default is **No**. Use `--overwrite` to replace it without a prompt, including
in non-interactive mode. This replaces the file rather than merging your changes.
Existing dependencies are never overwritten by `add`.

Presets can restyle existing CVA variants and add new values to supported string
axes. For example, add `brand` in the Creator, then use `<Badge variant="brand" />`
after installing Badge with that preset. A compound component can define
different classes for each part that uses the axis.

For a preset axis with a value list, the CLI also removes unlisted public string
variants. It preserves variants used by fixed internal calls. If the default is
removed, the CLI uses a remaining `props` value from the preset or the first
remaining value. It does not change an existing default that is still listed.
Existing code that explicitly uses removed variants must be updated.

The CLI reports changes it cannot apply safely. Boolean axes, new props, and
standalone prop defaults are not supported.

### list

List all items available in the registry. Use `--type` to filter by category.

```bash
npx rlz@latest list
```

| Flag           | Description                                   |
| -------------- | --------------------------------------------- |
| `--type`, `-t` | Filter by type: `component`, `hook`, or `lib` |

### info

Show detailed information about a registry item, including its dependencies and registry dependencies.

```bash
npx rlz@latest info <name>
```
