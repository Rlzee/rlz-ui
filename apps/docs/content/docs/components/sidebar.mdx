## Usage

```tsx
import { Sidebar } from "@/components/ui/sidebar";
```

```tsx
<Sidebar.Provider>
  <Sidebar>
    <Sidebar.Header />
    <Sidebar.Body>
      <Sidebar.Group>
        <Sidebar.GroupLabel>Navigation</Sidebar.GroupLabel>
        <Sidebar.GroupContent>
          <Sidebar.Menu>
            <Sidebar.MenuItem>
              <Sidebar.MenuButton>
                <Home />
                <span>Home</span>
              </Sidebar.MenuButton>
            </Sidebar.MenuItem>
          </Sidebar.Menu>
        </Sidebar.GroupContent>
      </Sidebar.Group>
    </Sidebar.Body>
    <Sidebar.Footer />
  </Sidebar>
  <Sidebar.Inset>
    <main>{/* page content */}</main>
  </Sidebar.Inset>
</Sidebar.Provider>
```

## API Reference

### Sidebar Provider

Wrap your layout with `<Sidebar.Provider>` to provide sidebar context to all child components.

| Prop           | Type                      | Default |
| -------------- | ------------------------- | ------- |
| `defaultOpen`  | `boolean`                 | `true`  |
| `open`         | `boolean`                 | -       |
| `onOpenChange` | `(open: boolean) => void` | -       |

### Sidebar

| Prop          | Type                                 | Default       |
| ------------- | ------------------------------------ | ------------- |
| `side`        | `"left" \| "right"`                  | `"left"`      |
| `variant`     | `"sidebar" \| "floating" \| "inset"` | `"sidebar"`   |
| `collapsible` | `"offcanvas" \| "icon" \| "none"`    | `"offcanvas"` |

`collapsible` controls how the sidebar collapses:

- `"offcanvas"` — slides out of view completely
- `"icon"` — collapses to show only icons
- `"none"` — always visible, cannot be collapsed

On mobile, the sidebar automatically renders as a `<Drawer>` regardless of the `collapsible` prop.

### Sidebar Trigger

Toggles the sidebar open and closed. Renders as a `<Button>`.

| Prop      | Type                     | Default     |
| --------- | ------------------------ | ----------- |
| `variant` | `ButtonProps["variant"]` | `"ghost"`   |
| `size`    | `ButtonProps["size"]`    | `"icon-md"` |

### Sidebar Menu Button

The main interactive element inside a menu item.

| Prop       | Type                            | Default   |
| ---------- | ------------------------------- | --------- |
| `variant`  | `"ghost" \| "primary"`          | `"ghost"` |
| `size`     | `"sm" \| "md" \| "lg"`          | `"md"`    |
| `isActive` | `boolean`                       | `false`   |
| `tooltip`  | `string \| Tooltip.Popup props` | -         |

When `collapsible="icon"` and a `tooltip` is provided, the tooltip is shown automatically when the sidebar is collapsed.
Supports the `render` prop for custom element rendering (e.g. a `<Link>`).

### Sidebar Menu Sub Button

Button used inside `<Sidebar.MenuSub>` for nested navigation items.

| Prop       | Type                   | Default   |
| ---------- | ---------------------- | --------- |
| `variant`  | `"ghost" \| "primary"` | `"ghost"` |
| `size`     | `"sm" \| "md"`         | `"md"`    |
| `isActive` | `boolean`              | `false`   |

Supports the `render` prop for custom element rendering.

### Sidebar Menu Action

An action button rendered on the right side of a menu item (e.g. a context menu trigger).

| Prop          | Type      | Default |
| ------------- | --------- | ------- |
| `showOnHover` | `boolean` | `false` |

When `showOnHover` is `true`, the action is hidden until the menu item is hovered or focused.
Supports the `render` prop for custom element rendering.

### Sidebar Group Label

Supports the `render` prop for custom element rendering.

### Sidebar Inset

Wrapper for the main content area. When `variant="inset"` is used on `<Sidebar>`, `<Sidebar.Inset>` adds the matching rounded style to the content area.

### useSidebar

Hook that exposes the sidebar context. Must be used inside `<Sidebar.Provider>`.

```tsx
const {
  state, // "expanded" | "collapsed"
  open, // boolean
  setOpen, // (open: boolean) => void
  isMobile, // boolean
  openMobile, // boolean
  setOpenMobile, // (open: boolean) => void
  toggleSidebar, // () => void
} = useSidebar();
```
