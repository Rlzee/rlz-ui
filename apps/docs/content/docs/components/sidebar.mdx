## Usage

```tsx
import { Sidebar } from "@/components/ui/sidebar";
```

```tsx
<Sidebar.Provider>
  <Sidebar>
    <Sidebar.Header />
    <Sidebar.Body>
      <Sidebar.Group>
        <Sidebar.GroupLabel>Navigation</Sidebar.GroupLabel>
        <Sidebar.List>
          <Sidebar.ButtonField>
            <Sidebar.Button isActive>
              <Home />
              Home
            </Sidebar.Button>
          </Sidebar.ButtonField>
        </Sidebar.List>
      </Sidebar.Group>
    </Sidebar.Body>
    <Sidebar.Footer />
  </Sidebar>
  <Sidebar.Inset>
    <main>{/* page content */}</main>
  </Sidebar.Inset>
</Sidebar.Provider>
```

## API Reference

### Sidebar Provider

Wrap your layout with `<Sidebar.Provider>` to provide sidebar context to all child components.

| Prop           | Type                      | Default |
| -------------- | ------------------------- | ------- |
| `defaultOpen`  | `boolean`                 | `true`  |
| `open`         | `boolean`                 | -       |
| `onOpenChange` | `(open: boolean) => void` | -       |

### Sidebar

| Prop          | Type                                 | Default       |
| ------------- | ------------------------------------ | ------------- |
| `side`        | `"left" \| "right"`                  | `"left"`      |
| `variant`     | `"sidebar" \| "floating" \| "inset"` | `"sidebar"`   |
| `collapsible` | `"offcanvas" \| "icon" \| "none"`    | `"offcanvas"` |

`collapsible` controls how the sidebar collapses:

- `"offcanvas"` — slides out of view completely
- `"icon"` — collapses to show only icons
- `"none"` — always visible, cannot be collapsed

On mobile, the sidebar automatically renders as a `<Drawer>` regardless of the `collapsible` prop.

### Sidebar Trigger

Toggles the sidebar open and closed. Renders as a `<Button>`.

| Prop      | Type                     | Default     |
| --------- | ------------------------ | ----------- |
| `variant` | `ButtonProps["variant"]` | `"ghost"`   |
| `size`    | `ButtonProps["size"]`    | `"icon-md"` |

### Sidebar Button

The main interactive element inside a `<Sidebar.List>`. Use `<Sidebar.ButtonField>` to wrap it when you need to render an action or badge on the right.

| Prop       | Type                                         | Default     |
| ---------- | -------------------------------------------- | ----------- |
| `variant`  | `"primary" \| "secondary" \| "destructive"`  | `"primary"` |
| `size`     | `"xs" \| "sm" \| "md" \| "lg" \| "xl"`       | `"md"`      |
| `isActive` | `boolean`                                    | `false`     |
| `tooltip`  | `string \| Tooltip.Popup props`              | -           |

When `collapsible="icon"` and a `tooltip` is provided, the tooltip is shown automatically when the sidebar is collapsed.
Supports the `render` prop for custom element rendering (e.g. a `<Link>`).

### Sidebar Button Field

Wraps a `<Sidebar.Button>` to position secondary content (such as a `<Badge>` or action button) on the right side of the item.

### Sidebar Sub

Collapsible container for nested navigation. Manages its own open state and expands the sidebar if it is collapsed.

| Prop           | Type                       | Default |
| -------------- | -------------------------- | ------- |
| `size`         | `SidebarButtonSize`        | `"md"`  |
| `defaultOpen`  | `boolean`                  | `false` |
| `open`         | `boolean`                  | -       |
| `onOpenChange` | `(open: boolean) => void`  | -       |

### Sidebar Sub Trigger

Button that toggles a `<Sidebar.Sub>`. Renders a chevron that rotates when the panel is open.

### Sidebar Sub List

Collapsible panel containing the nested `<Sidebar.SubButton>` items.

### Sidebar Sub Button

Nested navigation item. Its `size` is derived from the parent `<Sidebar.Sub>` unless overridden.

### Sidebar Nav

Container for a stack-based, multi-page navigation flow. Renders the current page and animates transitions.

| Prop            | Type                       | Default |
| --------------- | -------------------------- | ------- |
| `defaultPath`   | `string[]`                 | `[]`    |
| `path`          | `string[]`                 | -       |
| `onPathChange`  | `(path: string[]) => void` | -       |

### Sidebar Nav Page

Content shown when its `name` matches the current path.

| Prop   | Type     | Default |
| ------ | -------- | ------- |
| `name` | `string` | -       |

### Sidebar Nav Trigger

Pushes a new page onto the navigation stack.

| Prop      | Type                                        | Default     |
| --------- | ------------------------------------------- | ----------- |
| `to`      | `string`                                    | -           |
| `variant` | `"primary" \| "secondary" \| "destructive"` | `"primary"` |
| `size`    | `"xs" \| "sm" \| "md" \| "lg" \| "xl"`      | `"md"`      |

### Sidebar Nav Back

Pops the current page off the navigation stack.

| Prop      | Type                                        | Default     |
| --------- | ------------------------------------------- | ----------- |
| `variant` | `"primary" \| "secondary" \| "destructive"` | `"primary"` |
| `size`    | `"xs" \| "sm" \| "md" \| "lg" \| "xl"`      | `"md"`      |
| `tooltip` | `string \| Tooltip.Popup props`             | `"back"`    |

### Sidebar Group Label

Supports the `render` prop for custom element rendering.

### Sidebar Inset

Wrapper for the main content area. When `variant="inset"` is used on `<Sidebar>`, `<Sidebar.Inset>` adds the matching rounded style to the content area.

### useSidebar

Hook that exposes the sidebar context. Must be used inside `<Sidebar.Provider>`.

```tsx
const {
  state, // "expanded" | "collapsed"
  open, // boolean
  setOpen, // (open: boolean) => void
  isMobile, // boolean
  openMobile, // boolean
  setOpenMobile, // (open: boolean) => void
  toggleSidebar, // () => void
} = useSidebar();
```

### useSidebarNav

Hook that exposes the navigation context. Must be used inside `<Sidebar.Nav>`.

```tsx
const {
  current, // string | null
  direction, // "forward" | "back"
  push, // (name: string) => void
  pop, // () => void
} = useSidebarNav();
```
